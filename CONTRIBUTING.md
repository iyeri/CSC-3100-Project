CONTRIBUTING.md

1. Use prettier to format all js, jsx, ts, tsx, css, md, & json files in repo
   using the following command in the root directory: 'npm run format'.

2. Use eslint to check for formatting issues for .js files within the backend
   & frontend. You can either run 'npm run lint' to check all .js files or you
   can run 'npx eslint FILENAME' to check a specific file. (eslint is currently
   only setup for .js files. You can edit this in the individual eslint.config.js
   files within the frontend & backend.)
